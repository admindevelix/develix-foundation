# Manifesto Develix

> Não construímos software.
>
> Construímos capacidade.

---

# O problema

A maioria das empresas desenvolve sistemas.

Nós acreditamos que isso é pouco.

Sistemas envelhecem.

Tecnologias mudam.

Clientes mudam.

Mercados mudam.

Se cada novo projeto começa do zero, estamos condenados a repetir o mesmo trabalho para sempre.

---

# Nossa visão

Cada produto desenvolvido deve tornar o próximo mais fácil.

Cada problema resolvido deve se transformar em uma nova capacidade da plataforma.

Cada cliente deve financiar a evolução de uma tecnologia que beneficiará todos os clientes seguintes.

Não acumulamos apenas projetos.

Acumulamos conhecimento.

---

# A plataforma é o produto

Para muitas empresas, o software entregue ao cliente é o produto.

Para a Develix, não.

O software entregue é apenas uma consequência.

Nosso verdadeiro produto é nossa plataforma tecnológica.

Ela é o ativo mais importante da empresa.

Ela é o que cresce todos os dias.

Ela é o que torna possível entregar mais valor com menos esforço.

---

# Pensamento de longo prazo

Nunca tomamos decisões apenas para resolver o problema atual.

Toda decisão deve responder uma pergunta:

"Isso torna a Develix mais forte daqui a cinco anos?"

Se a resposta for não, provavelmente existe uma decisão melhor.

---

# Simplicidade

Complexidade não é sinal de inteligência.

É sinal de desperdício.

Buscamos soluções simples.

Código simples.

Arquiteturas simples.

Processos simples.

Porque simplicidade escala.

Complexidade cobra juros.

---

# Independência

Valorizamos o conhecimento interno.

Utilizamos ferramentas externas quando fazem sentido.

Mas evitamos depender delas para nossa existência.

Queremos compreender profundamente aquilo que construímos.

Não apenas utilizar.

---

# Qualidade

Velocidade sem qualidade gera retrabalho.

Retrabalho gera atraso.

Atraso gera custo.

Por isso qualidade nunca é opcional.

Testes fazem parte do desenvolvimento.

Documentação faz parte do desenvolvimento.

Refatoração faz parte do desenvolvimento.

---

# Automação

Se uma tarefa precisa ser repetida várias vezes, ela provavelmente deve ser automatizada.

Automação libera pessoas para pensar.

Pensar gera inovação.

---

# Pessoas

Tecnologia existe para ampliar pessoas.

Nunca para substituí-las.

Valorizamos profissionais curiosos.

Pessoas que aprendem.

Pessoas que compartilham conhecimento.

Pessoas que melhoram continuamente.

---

# Confiança

Queremos que nossos clientes pensem:

"A Develix resolve."

Não apenas entrega software.

Resolve problemas.

Encontra caminhos.

Simplifica processos.

Cria oportunidades.

Essa confiança vale mais do que qualquer tecnologia.

---

# Nosso compromisso

Cada linha de código deve tornar a próxima linha melhor.

Cada projeto deve fortalecer a plataforma.

Cada decisão deve aproximar a Develix do futuro que queremos construir.

Não estamos apenas criando sistemas.

Estamos construindo uma empresa capaz de criar qualquer sistema.

Essa é a Develix.
