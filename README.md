# Develix Foundation

O **Develix Foundation** é a fonte oficial de conhecimento da plataforma Develix.

Este repositório define os princípios, a arquitetura, os padrões e as decisões que orientam o desenvolvimento de todos os projetos da empresa.

O objetivo do Foundation é garantir que todas as decisões técnicas sejam consistentes, documentadas e alinhadas com a filosofia da Develix.

---

# Ordem de leitura

Ao iniciar um novo projeto ou uma nova conversa sobre desenvolvimento, a leitura deve seguir esta ordem:

1. `MANIFESTO.md`
2. `PHILOSOPHY.md`
3. `PRINCIPLES.md`
4. `ARCHITECTURE.md`
5. `DECISIONS.md`
6. `ROADMAP.md`
7. `CODING_STANDARD.md`
8. `TESTING.md`
9. `AI_CONTEXT.md`

Após essa leitura, consulte os documentos específicos conforme necessário:

* `ADR/`
* `TEMPLATES/`

# Regras

Todo desenvolvimento da Develix deve seguir as definições deste repositório.

Nenhuma decisão arquitetural deve contrariar um documento existente sem que a mudança seja previamente registrada em uma ADR.

Novas abstrações somente devem ser criadas quando resolverem uma necessidade real identificada durante o desenvolvimento de um produto.

O Foundation evolui continuamente juntamente com os produtos da Develix.

---

# Objetivo

O Foundation existe para tornar o desenvolvimento previsível, consistente e escalável.

Ele preserva o conhecimento arquitetural da empresa, reduz decisões repetidas e permite que novos projetos sejam construídos seguindo os mesmos princípios, padrões e visão de longo prazo.
