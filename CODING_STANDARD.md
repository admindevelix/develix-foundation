# Padrão de Código

## Objetivos

Código simples.

Código legível.

Código previsível.

---

## Regras

Sempre utilizar:

- strict_types
- namespaces
- tipagem

---

## Métodos

Métodos pequenos.

Uma responsabilidade por método.

---

## Classes

Uma responsabilidade por classe.

---

## Comentários

Comentar apenas quando necessário.

O código deve explicar a maior parte do comportamento.
