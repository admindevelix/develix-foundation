# Architecture Decision Records (ADR)

Os ADRs registram decisões arquiteturais permanentes da plataforma Develix.

O objetivo é preservar o histórico técnico e explicar por que determinada decisão foi tomada.

## Regras

* Cada decisão possui um arquivo próprio.
* ADRs aceitas não devem ser reescritas.
* Caso uma decisão seja substituída, uma nova ADR deve ser criada referenciando a anterior.
* Toda decisão arquitetural relevante deve possuir um ADR.

## Estrutura

Os arquivos seguem a convenção:

* 0001-...
* 0002-...
* 0003-...

A numeração nunca é reutilizada.

## Benefícios

* Preserva conhecimento técnico.
* Facilita onboarding.
* Evita rediscussões.
* Documenta a evolução da plataforma.
